5. Подбор привода: винт, редуктор, мотор

Формулы: момент на моторе T = F·p / (2π·η·i), обороты n = v / p · i · 60. Трапецеидальный винт самотормозящий, если угол подъёма резьбы λ = arctg(p / π·d₂) меньше угла трения ρ′ = arctg(μ / cos 15°), при μ = 0.1. Шаговому мотору нужен запас по моменту ×2, серво — ×1.3. Винт проверяется на продольный изгиб по Эйлеру: Pкр = π²·E·I / (K·L)², I = π·d₃⁴/64, запас ≥ 3. Входные обороты червячного домкрата ограничены 1500 об/мин. Характеристики моторов (при питании драйвера 36–48 В) и КПД редукторов типовые для класса: перед покупкой сверить с каталогом.
