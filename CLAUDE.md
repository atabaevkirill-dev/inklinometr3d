# inklinometr3d — платформа с выравниванием по 3 точкам

Отвечай на русском, кратко и по делу. Пользователь — инженер-практик, строит реальную установку.

## Цель проекта

Платформа (в большой версии 1000×1000 мм) поднимается на заданную высоту тремя приводами и держит
горизонт «мёртво» по трём инклинометрам. Путь: симуляция → расчёты → тестовый стенд 200×200 мм на ESP32
с ручным выравниванием → добавить моторы → перенести на большую конструкцию.

## Что где

| Путь | Что |
|---|---|
| `index.html` + `js/main.js` | 3D-симуляция (three.js r147 с CDN), панель «Железо» |
| `js/config.js` | параметры; `js/hardware.js` — каталог приводов/датчиков и «проверка комплекта» |
| `js/physics.js` | модель железа (Plant): опоры, пол, груз, податливость, люфт, утечки, датчики и их отказы |
| `js/controller.js` | контроллер (без доступа к модели): режимы IDLE/MOVING/SETTLE/LEVELING/HOLD/ESTOP/FAULT, синхронный подъём, выравнивание (непрерывное или шагами для приводов с vMin), голосование 2 из 3, защиты |
| `js/sim.js` | связка: физика 200 Гц, контроллер 50 Гц |
| `calc.html` + `js/calc.js` + `js/calc-ui.js` | расчёт «3 опоры против 4»: МКЭ пластины (элемент ACM), статика, устойчивость, подбор привода |
| `live.html` + `js/live.js` + `js/live-sources.js` | живые данные со стенда: USB (Web Serial) / Wi-Fi (WebSocket) / демо |
| `firmware/esp32-leveler/` | прошивка ESP32 (PlatformIO), см. её README |
| `tests/` | безголовые тесты симуляции (node) |

Все JS — классические скрипты без сборки, общий объект `window.LP` (в node — `globalThis.LP`).
Модули physics/controller/sim/hardware/calc грузятся и в браузере, и в node.

## Соглашения

- Единицы: мм, с, кг, Н, градусы. Оси платформы: X — вправо, Y — назад (от оператора), Z — вверх.
  Наклон X > 0 — правый край выше; Y > 0 — задний край выше. В three.js: P(x,y,z) → V(x, z, −y).
- Контроллер видит только измерения (энкодеры, инклинометры, датчик высоты) — не давать ему доступ к Plant.
- Протокол плата↔сайт описан в `firmware/esp32-leveler/README.md`. Меняешь формат — меняй одновременно
  прошивку (`lib/leveler_core`), `js/live-sources.js` (демо повторяет прошивку) и `js/live.js`. Скорость порта 230400.
- Пресет привода в `js/hardware.js` согласован с рекомендацией расчёта (червячный домкрат Tr20×4 1:10 + NEMA 23, 5 мм/с).
- Тексты интерфейса — по-русски.

## Принятые решения (с обоснованием в calc.html)

- **3 точки, а не 4**: статически определимо, ошибка высоты опоры не перераспределяет нагрузку
  (у 4 опор 1 мм ошибки ≈ ±300–500 Н, опора отрывается при ~1–1.6 мм). Груз фиксированный — опоры ставятся под его ЦТ.
- **Ровность верха** даёт жёсткость плиты, не выравнивание. Крепление штоков — «сфера–паз–плоскость».
- **Привод**: червячный домкрат с трапецеидальным винтом + шаговый с энкодером (самотормозящий в статике). Гидравлика избыточна.
- **Датчики**: 3 инклинометра ради голосования 2 из 3 (1 — отказ не виден, 2 — только остановка).
  Одинаковый отказ двух датчиков голосованием не ловится — для этого проверка правдоподобия по энкодерам (`plausDeg`).
- **Стенд**: ESP32 + 3× Murata SCL3300 (альтернативы ADXL355, MPU-6050 для проверки связи);
  самовыравнивание тремя сервами с рычагом 15 мм — Feetech STS3215 по шине (ШИМ-сервы как вариант).
  Регулятор `Leveler` в `lib/leveler_core`; его копия — в демо `js/live-sources.js` (держать одинаковыми).

## Состояние и что дальше

- Готово: симуляция, расчёты (МКЭ подтверждён независимым пересчётом), прошивка стенда с самовыравниванием сервами,
  страница живых данных (USB/Wi-Fi/демо, калибровка разворотом, подсказки по винтам, панель серв, запись CSV).
- Прошивка не собиралась настоящим тулчейном ESP32 и не проверялась на железе — при первой сборке возможны мелкие правки.
- Дальше: собрать стенд и прогнать эксперимент (калибровка разворотом, ручное выравнивание, авто на сервах, запись CSV) →
  выводы по точности → большая конструкция на винтовых домкратах с шаговыми моторами (логика `js/controller.js`).
