# Выравнивание платформы по 3 точкам — симуляция

Плита 1000×1000 мм на трёх актуаторах (опоры A, B, C), три двухосевых инклинометра (И1–И3).
Система поднимает плиту на заданную высоту, выравнивает её в горизонт и держит горизонт
при изменении нагрузки и просадке опор.

## Запуск

Открыть `index.html` в браузере (нужен интернет для three.js) или через локальный сервер:

```bash
python3 -m http.server 8765
```

→ http://localhost:8765

Страницы: `index.html` — симуляция, `calc.html` — расчёт «3 опоры против 4», `live.html` — живые данные со стенда.

Автотесты логики (без браузера):

```bash
node tests/run-sim.js && node tests/run-hardware.js
```

## Тестовый стенд 200×200 мм (ESP32)

Прошивка — [firmware/esp32-leveler](firmware/esp32-leveler/README.md): ESP32 + 3 инклинометра (рекомендую Murata SCL3300)
+ 3 сервы с рычагом для самовыравнивания (рекомендую Feetech STS3215). Данные на `live.html` по USB или Wi-Fi.
Там же: какие датчики и сервы брать, что купить, схема подключения, порядок эксперимента.
На сайте — калибровка разворотом на 180°, подсказка «какой винт на сколько оборотов», автовыравнивание сервами,
запись CSV, демо без железа.

## Как работает

1. **Синхронный подъём.** Все три опоры идут по одному трапециевидному профилю.
   Если одна отстаёт больше чем на 2 мм, профиль притормаживает и ждёт её.
   Поэтому плита поднимается без перекоса даже при разной скорости моторов.
2. **Успокоение** 1 с.
3. **Выравнивание.** По наклону X/Y считается, на сколько каждая опора выше горизонта:
   `εᵢ = tg(X)·xᵢ + tg(Y)·yᵢ`. Скорость опоры `vᵢ = −Kp·εᵢ` плюс общая поправка высоты.
   Чистый наклон не сдвигает центр плиты, поэтому высота и горизонт регулируются независимо.
   Есть стратегия «только подъём»: опоры только поднимаются до уровня самой высокой.
4. **Удержание (стабилизация).** Моторы стоят. Если наклон больше 0.05° или высота уходит
   больше чем на 1.5 мм дольше 1 с, система снова выравнивает.

**Почему 3 точки.** Через три точки всегда проходит одна плоскость: плита не качается,
нагрузка на опоры однозначна. С четырьмя опорами одна «висела» бы.

**Почему 3 инклинометра.** Для наклона хватает одного двухосевого. Три дают голосование
«2 из 3»: берётся медиана, а датчик, который расходится с остальными, шумит, завис или
пропал со связи, исключается автоматически. При двух неисправных — авария.

**Защиты:** наклон > 5°, опора не движется при команде (перегрузка/заклинивание),
конец хода, отказ датчиков, аварийный стоп (Esc). Авария держится до «Сброса».

## Железо (панель «Железо» в симуляции)

Выбор меняет модель на лету: скорость, жёсткость, люфт, самоторможение, утечки, шум и дрейф датчиков.
Справа — автоматическая «проверка комплекта»: держит ли он горизонт «мёртво».

| Привод | Держит без питания | Особенность |
|---|---|---|
| Винтовой домкрат (трап. винт) + шаговый | да, самоторможение | **рекомендую** |
| ШВП + серво с тормозом | да, тормоз | быстрый, дороже |
| ШВП + серво без тормоза | нет — при аварии плита падает | |
| Линейный актуатор 24 В DC | да | мягкий, люфт, выравнивает шагами |
| Гидроцилиндр | нет, утечки | плита садится, нужна постоянная подстройка |

Инклинометры: 1 шт. — отказ не обнаружить; 2 шт. — обнаружит, но только остановится;
3 шт. — исключит неисправный и продолжит работу.

## Расчёт «3 опоры против 4» — `calc.html`

МКЭ пластины (элемент Кирхгофа ACM, проверен точным решением — ошибка 0.005%), статика,
устойчивость, ровность плиты, кинематика шарниров, подбор привода. Вводите массу и положение груза.

Коротко:
- **3 точки — правильно**: плоскость всегда однозначна, ошибка высоты опоры не перераспределяет нагрузку.
- **4 опоры**: 1 мм ошибки высоты одной опоры меняет нагрузки на ±313 Н, при ~1.7 мм опора полностью
  разгружается — нужны датчики силы на опорах.
- **Груз фиксированный** — опоры ставятся под него (расчёт подбирает треугольник): нагрузки выравниваются,
  устойчивость как у 4 опор.
- **Ровность верха даёт жёсткость плиты**, а не выравнивание: алюминий 30 мм под 300 кг — ~0.55 мм.
- **Крепление «сфера–паз–плоскость»**: держит плиту вбок и не мешает наклону.
- **Привод**: червячный домкрат с трапецеидальным винтом + шаговый мотор с энкодером. Самотормозящий,
  держит без питания и без тормоза. Гидравлика не нужна.

## Структура

| Файл | Что внутри |
|---|---|
| `js/config.js` | все параметры: геометрия, моторы, датчики, коэффициенты |
| `js/physics.js` | модель «железа»: опоры, пол, груз, податливость, датчики, отказы |
| `js/controller.js` | контроллер: режимы, подъём, выравнивание, слияние датчиков, защиты |
| `js/sim.js` | связка: физика 200 Гц, управление 50 Гц |
| `js/view3d.js`, `js/charts.js`, `js/main.js` | 3D, графики, интерфейс |
| `js/hardware.js` | каталог железа и проверка комплекта |
| `js/calc.js`, `calc.html`, `js/calc-ui.js` | расчёт 3 vs 4 опоры, МКЭ плиты, подбор привода |
| `live.html`, `js/live.js`, `js/live-sources.js` | живые данные со стенда: USB / Wi-Fi / демо |
| `firmware/esp32-leveler/` | прошивка стенда для ESP32 (PlatformIO) |
| `tests/run-sim.js` | 25 сценариев, включая 60 случайных прогонов |
| `tests/run-hardware.js` | 77 сценариев: все сочетания железа, удержание, отказы |

Контроллер не видит модель — только измерения (энкодеры, инклинометры, дальномер).
Его можно перенести на реальный контроллер почти без изменений.
